# Swiggy Data Analysis

## Project Overview
This project focuses on analyzing Swiggy restaurant data using Python and Pandas. The aim is to understand restaurant details, ratings, pricing, food categories, and other useful patterns.

## Dataset
The dataset contains restaurant information, including:
- Restaurant names
- Restaurant types
- Ratings and number of ratings
- Average cost for two people
- Online ordering availability
- Table booking availability
- Cuisine types
- Location and address

## Tools and Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Work
- Data loading
- Data cleaning
- Handling missing values
- Removing unnecessary columns
- Adding and deleting columns
- Data analysis and exploration

## Key Insights
The analysis explores restaurant ratings, average costs, cuisine types, locations, and online ordering patterns.

## Files Included
- `Swiggy_Analysis.ipynb` – Jupyter Notebook containing the analysis.
- `swiggy.csv` – Dataset used for the project.
